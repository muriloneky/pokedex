# 🔴 Pokédex

![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

Pokédex feita com HTML, CSS e JavaScript puro, que busca os dados na [PokéAPI](https://pokeapi.co/).

<p align="center">
  <img src="pokedex.png" alt="Tela da Pokédex" width="260"/>
</p>

## ✨ Funcionalidades

- Busca de Pokémon por **nome** ou **número**
- Botões **Anterior** e **Próximo** para navegar pela lista
- Imagem animada, nome e número do Pokémon
- Mensagem quando o Pokémon não é encontrado

## 🧠 O que pratiquei

- Consumo de API com `fetch` e `async/await`
- Manipulação do DOM (`querySelector`, `innerHTML`)
- Tratamento de eventos de formulário e botões

## ▶️ Como usar

Não precisa instalar nada: baixe o projeto e abra o `index.html` no navegador.
